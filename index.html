Configurações

Conecte sua conta do Mercado Pago.

Mercado Pago → Seu negócio → Configurações → Credenciais. Use o token de produção para receber de verdade.

Recomendado. O Mercado Pago bloqueia chamadas direto do navegador (CORS) — veja o código abaixo.

Servidor intermediário (Vercel)

Seu token dá acesso à sua conta. Guardado só neste navegador ele fica exposto; o ideal é deixá-lo na variável MP_TOKEN do servidor e não preencher o campo acima.

Crie o arquivo api/mp.js no seu projeto Vercel:

export default async function handler(req, res) {
  res.setHeader('Access-Control-Allow-Origin', '*');
  res.setHeader('Access-Control-Allow-Headers', 'Content-Type');
  if (req.method === 'OPTIONS') return res.status(200).end();
  const { path, method = 'GET', body, token } = req.body || {};
  if (!path || !path.startsWith('/')) return res.status(400).json({ error: 'path inválido' });
  const r = await fetch('https://api.mercadopago.com' + path, {
    method,
    headers: {
      Authorization: 'Bearer ' + (process.env.MP_TOKEN || token),
      'Content-Type': 'application/json'
    },
    body: body ? JSON.stringify(body) : undefined
  });
  res.status(r.status).json(await r.json());
}
